NotaRequisitos de las funciones auxiliares

Las filas representan individuos y las columnas, variables. Para k-means se necesitan variables numéricas sin valores ausentes; deben escalarse cuando sus unidades no sean comparables. Los objetos utilizados por las funciones auxiliares deben proceder de kmeans() o cluster::pam(). Las particiones que se comparen deben contener los mismos individuos y estar en el mismo orden; la candidata no debe tener más grupos que la referencia.

6.1 Motivación aplicada

En lugar de construir una jerarquía completa, a veces queremos una partición directa en \(k\) grupos. k-means y PAM son dos métodos clásicos para ese objetivo.

La diferencia principal es qué representa a cada grupo. k-means usa centroides, que son medias y no tienen por qué corresponder a observaciones reales. PAM usa medoides, que son individuos reales del dataset.

Nota

k-means busca grupos compactos alrededor de centroides; si esa geometría no representa bien los datos, el resultado puede ser técnicamente correcto pero sustantivamente débil.

ImportanteEl representante define el grupo

Elegir entre k-means y PAM no es solo elegir un algoritmo. Supone decidir si un grupo debe resumirse mediante una media ideal o mediante una observación real representativa. Esa decisión determina la función objetivo, la sensibilidad a valores extremos y el tipo de datos que podemos utilizar.

6.2 Qué es una partición

Una partición asigna cada individuo a un único grupo. Si tenemos \(n\) individuos y queremos \(K\) clusters, buscamos conjuntos \(C_1,\ldots,C_K\) tales que:

  • \(C_g \cap C_h = \varnothing\) si \(g \neq h\);
  • \(C_1 \cup \cdots \cup C_K = \{1,\ldots,n\}\);
  • cada individuo pertenece a un solo cluster.

La partición no tiene niveles intermedios como un dendrograma. Por eso hay que fijar o seleccionar \(K\).

6.3 k-means: función objetivo

k-means busca \(K\) centroides \(\mu_1,\ldots,\mu_K\) y una asignación de individuos a clusters que minimice la suma de cuadrados dentro de los grupos:

\[ W_K=\sum_{g=1}^{K}\sum_{i \in C_g}\lVert x_i-\mu_g\rVert^2. \]

Para una partición fija, el mejor centroide de cada cluster es su media:

\[ \mu_g=\frac{1}{|C_g|}\sum_{i \in C_g}x_i. \]

La función objetivo penaliza distancias euclídeas al cuadrado. Por eso k-means está muy ligado a variables numéricas, escalado y clusters aproximadamente esféricos.

6.4 Algoritmo de Lloyd

El algoritmo más habitual de k-means alterna dos pasos:

  1. Asignación: cada individuo se asigna al centroide más cercano:

\[ c_i=\arg\min_{g=1,\ldots,K}\lVert x_i-\mu_g\rVert^2. \]

  1. Actualización: cada centroide se recalcula como la media de los individuos asignados:

\[ \mu_g^{nuevo}=\frac{1}{|C_g|}\sum_{i:c_i=g}x_i. \]

Estos pasos se repiten hasta que las asignaciones no cambian o hasta alcanzar un número máximo de iteraciones. En cada iteración, la suma de cuadrados interna no aumenta. El algoritmo converge, pero puede converger a un óptimo local.

6.5 Inicialización y semillas

Como k-means puede terminar en soluciones distintas según los centros iniciales, conviene usar varias inicializaciones. En R, nstart = 25 ejecuta el algoritmo desde 25 inicios y conserva la mejor solución según la función objetivo.

6.7 Demo interactivo: evolución de k-means

El siguiente bloque genera un pequeño control deslizante para ver varias iteraciones de k-means sobre dos variables de mtcars. No usa paquetes externos; solo HTML y JavaScript en la salida HTML de Quarto.

Código 
X_demo <- scale(mtcars[, c("mpg", "wt")])
K <- 3
set.seed(1)
centros <- X_demo[sample(seq_len(nrow(X_demo)), K), , drop = FALSE]
historial <- list()

for (iter in 1:8) {
  distancias <- sapply(seq_len(K), function(g) {
    rowSums((X_demo - matrix(centros[g, ], nrow(X_demo), 2, byrow = TRUE))^2)
  })
  cl <- max.col(-distancias)
  historial[[iter]] <- list(iter = iter, puntos = X_demo, centros = centros, cluster = cl)
  nuevos <- do.call(rbind, lapply(seq_len(K), function(g) colMeans(X_demo[cl == g, , drop = FALSE])))
  if (max(abs(nuevos - centros)) < 1e-8) {
    centros <- nuevos
    break
  }
  centros <- nuevos
}

xlim <- range(X_demo[, 1], centros[, 1])
ylim <- range(X_demo[, 2], centros[, 2])
esc <- function(z, lim, a, b) a + (z - lim[1]) / diff(lim) * (b - a)

slides <- vapply(historial, function(h) {
  pts <- paste(sprintf(
    "{x:%.2f,y:%.2f,c:%d}",
    esc(h$puntos[, 1], xlim, 30, 470),
    esc(h$puntos[, 2], ylim, 270, 30),
    h$cluster
  ), collapse = ",")
  ctr <- paste(sprintf(
    "{x:%.2f,y:%.2f,c:%d}",
    esc(h$centros[, 1], xlim, 30, 470),
    esc(h$centros[, 2], ylim, 270, 30),
    seq_len(K)
  ), collapse = ",")
  sprintf("{label:'Iteracion %d', points:[%s], centers:[%s]}", h$iter, pts, ctr)
}, character(1))

6.9 Elección del número de clusters

6.9.1 Método del codo

El método del codo inspecciona cómo disminuye la variabilidad interna al aumentar \(K\):

\[ W_K=\sum_{g=1}^{K}\sum_{i \in C_g}\lVert x_i-\mu_g\rVert^2. \]

Como \(W_K\) siempre disminuye al aumentar \(K\), buscamos un punto donde la mejora adicional empieza a ser pequeña.

Código 
grafico_codo_kmeans(
  datos_cluster,
  k = 1:8,
  nstart = 25,
  semilla = 123
)

El codo rara vez es completamente objetivo. Sirve como guía visual.

La silhouette, desarrollada en Sección 5.14.1 para comparar cortes de un árbol, también puede evaluar particiones producidas por k-means, PAM u otros algoritmos. En ese caso se sustituyen las asignaciones de cutree() por las de cada partición candidata, manteniendo una distancia coherente con la geometría del método.

6.9.2 Gap statistic

El gap statistic compara la variabilidad interna observada con la esperada bajo una distribución de referencia sin estructura clara:

\[ Gap(K)=E^*[\log(W_K^*)]-\log(W_K). \]

Si el gap es grande, los clusters observados son más compactos de lo esperable bajo una nube sin estructura. En la práctica, se combina con interpretabilidad y estabilidad.

Código 
set.seed(123)
gap <- cluster::clusGap(
  datos_cluster,
  FUN = kmeans,
  K.max = 6,
  B = 20,
  nstart = 10
)
as_tibble(gap$Tab, rownames = "k") |>
  mutate(k = as.integer(k)) |>
  ggplot(aes(k, gap)) +
  geom_line() +
  geom_point(size = 2) +
  geom_errorbar(aes(ymin = gap - SE.sim, ymax = gap + SE.sim), width = 0.15) +
  labs(title = "Gap statistic", x = "k", y = "Gap") +
  theme_minimal()

6.10 Sensibilidad de k-means

k-means es sensible al escalado, outliers, variables irrelevantes y clusters no esféricos. También presupone que el promedio representa bien cada grupo.

Estas sensibilidades no son problemas independientes: todas cuestionan si el centroide y la distancia euclídea al cuadrado son una buena representación del problema. Una solución puede ser estable frente a semillas y, sin embargo, depender por completo de una variable dominante o de un outlier.

Código 
set.seed(123)
km_sin_escalar <- kmeans(datos_mtcars, centers = 3, nstart = 25)
kable(table(escalado = km3$cluster, sin_escalar = km_sin_escalar$cluster))

0 0 6
5 9 0
2 0 10

Un outlier puede arrastrar un centroide o incluso ocupar casi un cluster.

6.10.2 Clusters no esféricos

k-means separa el espacio mediante regiones de Voronoi alrededor de centroides. Las fronteras son lineales y los clusters esperados son compactos.

Código 
set.seed(99)
t <- seq(0, 2 * pi, length.out = 80)
anillo1 <- cbind(cos(t), sin(t)) + matrix(rnorm(160, sd = 0.05), ncol = 2)
anillo2 <- 2.3 * cbind(cos(t), sin(t)) + matrix(rnorm(160, sd = 0.05), ncol = 2)
anillos <- rbind(anillo1, anillo2)
km_anillos <- kmeans(anillos, centers = 2, nstart = 25)
tibble(x = anillos[, 1], y = anillos[, 2], cluster = factor(km_anillos$cluster)) |>
  ggplot(aes(x, y, color = cluster)) +
  geom_point(size = 1.8, alpha = 0.85) +
  coord_equal() +
  labs(title = "k-means ante formas no esféricas", color = "Cluster") +
  theme_minimal()

Aunque hay dos anillos naturales, k-means tiende a cortar por regiones convexas, no por forma anular.

6.11 Cuándo no usar k-means

No es buena elección si:

  • hay variables categóricas activas;
  • los clusters esperados son alargados, curvos o de densidad muy desigual;
  • hay muchos outliers;
  • el promedio no representa bien un grupo;
  • las variables relevantes están mezcladas con muchas variables irrelevantes;
  • el número de clusters no puede justificarse mínimamente.

6.12 k-medoids

k-medoids reemplaza centroides por medoides. Un medoide \(m_g\) es una observación real dentro del cluster \(C_g\). La función objetivo típica es:

\[ \sum_{g=1}^{K}\sum_{i \in C_g} d(x_i,m_g). \]

La asignación se hace al medoide más cercano. Luego se buscan medoides que reduzcan la suma de disimilitudes dentro de cada cluster.

Ventajas frente a k-means:

  • puede trabajar con cualquier matriz de disimilitudes razonable;
  • el representante de cada grupo es un individuo real;
  • suele ser más robusto ante outliers;
  • permite usar distancias como Gower para datos mixtos.

Desventajas:

  • puede ser más costoso computacionalmente;
  • sigue requiriendo elegir \(K\);
  • si la distancia no representa bien la pregunta, el resultado tampoco lo hará.

6.13 PAM: Partitioning Around Medoids

PAM es un algoritmo clásico de k-medoids. Tiene dos fases:

  1. BUILD: selecciona un conjunto inicial de medoides buscando reducir la disimilitud total;
  2. SWAP: prueba intercambios entre un medoide y un no medoide; acepta el intercambio si mejora la función objetivo.

La idea del paso SWAP es comparar el coste actual con el coste que se obtendría si un medoide \(m\) se reemplazara por una observación \(h\). Si la suma total de distancias al medoide más cercano disminuye, el intercambio mejora la partición.

6.15 Comparación entre k-means y PAM

Aspecto k-means PAM / k-medoids
Representante Centroide, media no necesariamente observada Medoide, observación real
Distancia natural Euclídea al cuadrado Cualquier disimilitud
Tipo de variables Numéricas Numéricas, categóricas o mixtas si hay distancia adecuada
Robustez ante outliers Menor Mayor
Coste computacional Menor Mayor
Interpretabilidad del representante Media abstracta Caso real representativo

Que ambas técnicas asignen igual a todos los individuos no vuelve equivalentes sus resultados. Los centroides siguen siendo medias potencialmente inexistentes y los medoides siguen siendo casos observados. A la inversa, algunas diferencias de asignación pueden limitarse a individuos fronterizos y no implicar perfiles globales incompatibles.

Como ambos ajustes anteriores contienen los mismos coches, también podemos comparar directamente sus asignaciones. La función alinea primero las etiquetas de PAM con las de k-means, porque los números de cluster son arbitrarios.

6.17 Estabilidad

Una partición útil no debería depender excesivamente de una semilla concreta. Podemos repetir el algoritmo con varias semillas y mirar la variabilidad de la función objetivo.

  datos = datos_cluster,
  k = 3,
  semillas = 1:20
)

evaluacion_semillas$tabla |>

Si hay mucha variabilidad, conviene aumentar nstart, revisar datos o plantear otro método.

La estabilidad tiene varias dimensiones:

  • algorítmica: cambia al modificar la semilla o la inicialización;
  • muestral: cambia al retirar o incorporar unas pocas observaciones;
  • metodológica: cambia al usar otra selección de variables, escalado o método;
  • interpretativa: los perfiles dejan de tener el mismo significado aunque las etiquetas parezcan similares.

nstart solo ayuda con la primera. No protege frente a datos mal preparados, outliers, una elección inadecuada de \(K\) o una geometría que no se ajuste al problema.

6.18 Cómo tomar la decisión

Pregunta Evidencia útil Advertencia
¿Es la media un representante razonable? centroides, dispersión y outliers una media puede no parecerse a ningún caso
¿Necesitamos un prototipo real? medoides y casos próximos el medoide tampoco resume toda la variación
¿Qué valores de \(K\) son defendibles? codo, silhouette, tamaños y perfiles ningún criterio identifica siempre un \(K\) verdadero
¿Depende de la inicialización? repeticiones y WSS igual WSS no implica necesariamente iguales etiquetas
¿Depende de pocas observaciones? análisis de sensibilidad robustez no convierte un dato erróneo en válido

La elección final debería indicar qué solución se prefiere, qué alternativa cercana también sería razonable y qué aspecto del resultado cambia entre ambas. Esto es más informativo que declarar ganador al método con una cifra ligeramente mejor.

6.19 Errores frecuentes

  • Elegir \(K\) solo por defecto.
  • No usar nstart y depender de una inicialización débil.
  • Aplicar k-means a variables categóricas codificadas arbitrariamente.
  • Usar k-means sin escalar variables en unidades distintas.
  • Interpretar centroides como observaciones reales.
  • Usar PAM sin justificar la matriz de disimilitudes.
  • Nombrar clusters sin revisar perfiles de variables.

6.20 Resumen del capítulo

k-means y PAM construyen particiones directas. k-means alterna asignación a centroides y actualización por medias, minimizando suma de cuadrados interna. PAM busca medoides reales y puede trabajar con disimilitudes generales. Ambos necesitan elegir \(K\), revisar estabilidad y caracterizar los clusters después de calcularlos.

## Motivación aplicada

En lugar de construir una jerarquía completa, a veces queremos una partición directa en $k$ grupos. k-means y PAM son dos métodos clásicos para ese objetivo.

La diferencia principal es qué representa a cada grupo. k-means usa centroides, que son medias y no tienen por qué corresponder a observaciones reales. PAM usa medoides, que son individuos reales del dataset.

::: {.callout-note}
k-means busca grupos compactos alrededor de centroides; si esa geometría no representa bien los datos, el resultado puede ser técnicamente correcto pero sustantivamente débil.
:::

::: {.callout-important title="El representante define el grupo"}
Elegir entre k-means y PAM no es solo elegir un algoritmo. Supone decidir si un
grupo debe resumirse mediante una **media ideal** o mediante una **observación
real representativa**. Esa decisión determina la función objetivo, la
sensibilidad a valores extremos y el tipo de datos que podemos utilizar.
:::

## Qué es una partición

Una partición asigna cada individuo a un único grupo. Si tenemos $n$ individuos y queremos $K$ clusters, buscamos conjuntos $C_1,\ldots,C_K$ tales que:

- $C_g \cap C_h = \varnothing$ si $g \neq h$;
- $C_1 \cup \cdots \cup C_K = \{1,\ldots,n\}$;
- cada individuo pertenece a un solo cluster.

La partición no tiene niveles intermedios como un dendrograma. Por eso hay que fijar o seleccionar $K$.

## k-means: función objetivo

k-means busca $K$ centroides $\mu_1,\ldots,\mu_K$ y una asignación de individuos a clusters que minimice la suma de cuadrados dentro de los grupos:

$$
W_K=\sum_{g=1}^{K}\sum_{i \in C_g}\lVert x_i-\mu_g\rVert^2.
$$

Para una partición fija, el mejor centroide de cada cluster es su media:

$$
\mu_g=\frac{1}{|C_g|}\sum_{i \in C_g}x_i.
$$

La función objetivo penaliza distancias euclídeas al cuadrado. Por eso k-means está muy ligado a variables numéricas, escalado y clusters aproximadamente esféricos.

## Algoritmo de Lloyd

El algoritmo más habitual de k-means alterna dos pasos:

1. **Asignación**: cada individuo se asigna al centroide más cercano:

$$
c_i=\arg\min_{g=1,\ldots,K}\lVert x_i-\mu_g\rVert^2.
$$

2. **Actualización**: cada centroide se recalcula como la media de los individuos asignados:

$$
\mu_g^{nuevo}=\frac{1}{|C_g|}\sum_{i:c_i=g}x_i.
$$

Estos pasos se repiten hasta que las asignaciones no cambian o hasta alcanzar un número máximo de iteraciones. En cada iteración, la suma de cuadrados interna no aumenta. El algoritmo converge, pero puede converger a un óptimo local.

## Inicialización y semillas

Como k-means puede terminar en soluciones distintas según los centros iniciales, conviene usar varias inicializaciones. En R, `nstart = 25` ejecuta el algoritmo desde 25 inicios y conserva la mejor solución según la función objetivo.

## Elección del número de clusters

### Método del codo

El método del codo inspecciona cómo disminuye la variabilidad interna al aumentar $K$:

$$
W_K=\sum_{g=1}^{K}\sum_{i \in C_g}\lVert x_i-\mu_g\rVert^2.
$$

Como $W_K$ siempre disminuye al aumentar $K$, buscamos un punto donde la mejora adicional empieza a ser pequeña.

```{r}
grafico_codo_kmeans(
  datos_cluster,
  k = 1:8,
  nstart = 25,
  semilla = 123
)
```

El codo rara vez es completamente objetivo. Sirve como guía visual.

La silhouette, desarrollada en @sec-silhouette para comparar cortes de un árbol, también puede evaluar particiones producidas por k-means, PAM u otros algoritmos. En ese caso se sustituyen las asignaciones de `cutree()` por las de cada partición candidata, manteniendo una distancia coherente con la geometría del método.

### Gap statistic

El gap statistic compara la variabilidad interna observada con la esperada bajo una distribución de referencia sin estructura clara:

$$
Gap(K)=E^*[\log(W_K^*)]-\log(W_K).
$$

Si el gap es grande, los clusters observados son más compactos de lo esperable bajo una nube sin estructura. En la práctica, se combina con interpretabilidad y estabilidad.

```{r}

  nstart = 10
```

## Cuándo no usar k-means

No es buena elección si:

- hay variables categóricas activas;
- los clusters esperados son alargados, curvos o de densidad muy desigual;
- hay muchos outliers;
- el promedio no representa bien un grupo;
- las variables relevantes están mezcladas con muchas variables irrelevantes;
- el número de clusters no puede justificarse mínimamente.

## k-medoids

k-medoids reemplaza centroides por medoides. Un medoide $m_g$ es una observación real dentro del cluster $C_g$. La función objetivo típica es:

$$
\sum_{g=1}^{K}\sum_{i \in C_g} d(x_i,m_g).
$$

La asignación se hace al medoide más cercano. Luego se buscan medoides que reduzcan la suma de disimilitudes dentro de cada cluster.

Ventajas frente a k-means:

- puede trabajar con cualquier matriz de disimilitudes razonable;
- el representante de cada grupo es un individuo real;
- suele ser más robusto ante outliers;
- permite usar distancias como Gower para datos mixtos.

Desventajas:

- puede ser más costoso computacionalmente;
- sigue requiriendo elegir $K$;
- si la distancia no representa bien la pregunta, el resultado tampoco lo hará.

## PAM: Partitioning Around Medoids

PAM es un algoritmo clásico de k-medoids. Tiene dos fases:

1. **BUILD**: selecciona un conjunto inicial de medoides buscando reducir la disimilitud total;
2. **SWAP**: prueba intercambios entre un medoide y un no medoide; acepta el intercambio si mejora la función objetivo.

La idea del paso SWAP es comparar el coste actual con el coste que se obtendría si un medoide $m$ se reemplazara por una observación $h$. Si la suma total de distancias al medoide más cercano disminuye, el intercambio mejora la partición.

```{r}
pam3 <- cluster::pam(datos_cluster, k = 3)
kable(table(pam = pam3$clustering, transmision = factor(mtcars$am, labels = c("automatico", "manual"))))

medoides_pam <- extraer_medoides(
  pam3,
  datos = mtcars,
  variables = variables_mtcars,
  id = "rownames"
)
kable(medoides_pam, digits = 2, caption = "Medoides")
```

## Comparación entre k-means y PAM

| Aspecto | k-means | PAM / k-medoids |
|---|---|---|
| Representante | Centroide, media no necesariamente observada | Medoide, observación real |
| Distancia natural | Euclídea al cuadrado | Cualquier disimilitud |
| Tipo de variables | Numéricas | Numéricas, categóricas o mixtas si hay distancia adecuada |
| Robustez ante outliers | Menor | Mayor |
| Coste computacional | Menor | Mayor |
| Interpretabilidad del representante | Media abstracta | Caso real representativo |

Que ambas técnicas asignen igual a todos los individuos no vuelve equivalentes
sus resultados. Los centroides siguen siendo medias potencialmente inexistentes
y los medoides siguen siendo casos observados. A la inversa, algunas diferencias
de asignación pueden limitarse a individuos fronterizos y no implicar perfiles
globales incompatibles.

Como ambos ajustes anteriores contienen los mismos coches, también podemos
comparar directamente sus asignaciones. La función alinea primero las etiquetas
de PAM con las de k-means, porque los números de cluster son arbitrarios.


Después de obtener clusters, hay que describirlos.

```{r}
resumen_kmeans |>
  kable()
```

También conviene revisar tamaños y dispersión interna:

```{r}
resumen_kmeans |>
  select(cluster, tamano = individuos) |>
  mutate(withinss = round(km3$withinss, 2)) |>
  kable()
```

Un cluster grande y heterogéneo puede indicar que $K$ es demasiado pequeño o que la geometría de k-means no encaja bien.

## Estabilidad

Una partición útil no debería depender excesivamente de una semilla concreta. Podemos repetir el algoritmo con varias semillas y mirar la variabilidad de la función objetivo.

```{r}
evaluacion_semillas <- evaluar_semillas_kmeans(
  datos = datos_cluster,
  k = 3,
  semillas = 1:20
)

evaluacion_semillas$tabla |>
  summarise(
    minimo = min(suma_cuadrados_interna),
    mediana = median(suma_cuadrados_interna),
    media = mean(suma_cuadrados_interna),
    maximo = max(suma_cuadrados_interna)
  ) |>
  kable(digits = 2)

evaluacion_semillas$grafico
```

Si hay mucha variabilidad, conviene aumentar `nstart`, revisar datos o plantear otro método.

La estabilidad tiene varias dimensiones:

- **algorítmica**: cambia al modificar la semilla o la inicialización;
- **muestral**: cambia al retirar o incorporar unas pocas observaciones;
- **metodológica**: cambia al usar otra selección de variables, escalado o método;
- **interpretativa**: los perfiles dejan de tener el mismo significado aunque
  las etiquetas parezcan similares.

`nstart` solo ayuda con la primera. No protege frente a datos mal preparados,
outliers, una elección inadecuada de $K$ o una geometría que no se ajuste al
problema.

## Cómo tomar la decisión

| Pregunta | Evidencia útil | Advertencia |
|---|---|---|
| ¿Es la media un representante razonable? | centroides, dispersión y outliers | una media puede no parecerse a ningún caso |
| ¿Necesitamos un prototipo real? | medoides y casos próximos | el medoide tampoco resume toda la variación |
| ¿Qué valores de $K$ son defendibles? | codo, silhouette, tamaños y perfiles | ningún criterio identifica siempre un $K$ verdadero |
| ¿Depende de la inicialización? | repeticiones y WSS | igual WSS no implica necesariamente iguales etiquetas |
| ¿Depende de pocas observaciones? | análisis de sensibilidad | robustez no convierte un dato erróneo en válido |

La elección final debería indicar qué solución se prefiere, qué alternativa
cercana también sería razonable y qué aspecto del resultado cambia entre
ambas. Esto es más informativo que declarar ganador al método con una cifra
ligeramente mejor.

## Errores frecuentes

- Elegir $K$ solo por defecto.
- No usar `nstart` y depender de una inicialización débil.
- Aplicar k-means a variables categóricas codificadas arbitrariamente.
- Usar k-means sin escalar variables en unidades distintas.
- Interpretar centroides como observaciones reales.
- Usar PAM sin justificar la matriz de disimilitudes.
- Nombrar clusters sin revisar perfiles de variables.

## Resumen del capítulo

k-means y PAM construyen particiones directas. k-means alterna asignación a centroides y actualización por medias, minimizando suma de cuadrados interna. PAM busca medoides reales y puede trabajar con disimilitudes generales. Ambos necesitan elegir $K$, revisar estabilidad y caracterizar los clusters después de calcularlos.
